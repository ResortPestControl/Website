# resortpestcontrol.com

Static marketing site. No dependencies.

    node build.mjs      # writes ./dist (pages, sitemap.xml, robots.txt, vercel.json)

- `site.mjs`: business facts (phone, address, areas, portal links). Keep in sync with the Google Business Profile.
- `content.mjs`: every page's title, meta description and body.
- `static/`: CSS and images, copied as-is.

Vercel: build command `node build.mjs`, output directory `dist`.
`vercel.json` is generated by the build (commit it). Old Wix URLs (/about-us, /ants, /cockroaches, /rodents, /pest-identification) 301 to the new pages.
